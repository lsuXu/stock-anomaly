# A股股票交易异动监控与未来推演测算系统

基于中国三大证券交易所（上交所、深交所、北交所）最新全面注册制交易规则，构建的**股票交易异动与严重异常波动量化监控与推演系统**。

---

## ⚡ 一键双击启动方式（无需命令行输入）

系统已为 macOS 及 Windows 用户制作了**双击自启动与自动打开浏览器脚本**：

### 🍎 macOS 用户（两种方式任选）：
1. **直接双击应用**：双击文件夹中的 **`启动A股异动监控.app`**（原生 Mac 应用程序，推荐）。
2. **双击脚本**：双击文件夹中的 **[`start.command`](file:///Users/jz/Documents/my_project/qa/start.command)** 或 **`启动系统.command`**。
   * *功能：自动检测环境、自动清理残留端口、启动服务并在 1 秒后自动唤起系统默认浏览器打开界面。*
   * *退出方式：直接在弹出的终端窗口按 `Ctrl + C`，或直接关闭终端窗口即可。*

### 🪟 Windows 用户：
* 双击文件夹中的 **[`start.bat`](file:///Users/jz/Documents/my_project/qa/start.bat)** 即可。

## 核心特性

1. **法定基准指数精准匹配**（杜绝绝大多数行情软件误用成份指的行业盲区）：
   - **沪市主板**（600/601/603/605）：匹配 **上证A指 (000002.SH)**
   - **深市主板**（000/001/002/003）：匹配 **深证A指 (399107.SZ)**
   - **创业板**（300/301）：匹配 **创业板综 (399102.SZ)**
   - **科创板**（688）：匹配 **科创50 (000688.SH)**
2. **法定三大监管窗口全覆盖**：
   - **3日普通异动**：沪深主板 $\pm 20\%$，创业板/科创板 $\pm 30\%$
   - **10日严重异动**：累计偏离达到 $+100\%$ / $-50\%$
   - **30日严重异动**：累计偏离达到 $+200\%$ / $-70\%$
3. **盘中实时与已确认收盘双模式**：
   - **盘中时段 (09:15 ~ 15:00)**：基准锁定为昨日确认收盘价，提供“今日收盘涨幅红线”与“从现价还能涨多少”两个关键指标。
   - **盘后时段 (15:00 之后)**：今日收盘已定，自动推演“下一个交易日涨幅红线”。
4. **未来自定义 $N$ 天动态推演与连板测算**：
   - 用户可自定义未来 $1 \sim 30$ 天。
   - **天天连板吃异动模拟**：自动预测若连续涨停，将在未来第几天首次吃严重异动。
5. **高可用真实行情通道**：
   - 接入腾讯财经官方 CDN 行情通道（备用东财通道），支持全量 A 股真实个股（如 `000530 冰山冷热`）及官方综合指数。
   - 零 Token、免鉴权、零安装依赖。

## 命令行高级用法 (CLI)

```bash
# 查询股票 (如 000530 冰山冷热)，未来 3 天推演
python3 main.py --code 000530 --days 3

# 自定义假定未来基准指数涨跌幅
python3 main.py --code 300059 --days 5 --assume-index 0.01

# 启动 Web 仪表盘
python3 main.py --server --port 8080
```
